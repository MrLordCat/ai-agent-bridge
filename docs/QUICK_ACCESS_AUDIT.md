# Аудит и унификация Quick Access

Дата: 2026-10-15. Исходная версия: 1.17.13.

## Подтверждённые проблемы

| Приоритет | Наблюдение | Последствие | Исправление |
|---|---|---|---|
| P1 | Token Usage вручную перечисляет четыре источника, хотя история уже поддерживает `api` | Записанная история API-профилей скрыта | Строить раздел по `TOKEN_USAGE_PROVIDERS` |
| P1 | `quickAccessApiProviders()` ожидает чтения всех бюджетов | Медленный API задерживает весь Quick Access | Возвращать метаданные/кеш сразу и обновлять бюджеты в фоне |
| P2 | `getProviderSnapshots()` вызывается разными getters и в цикле API-профилей | Одна отрисовка может смешать разные состояния | Один снимок на построение дерева |
| P2 | `runtimeMetricItems` и `providerRuntimeItems` отдельно строят одинаковые показатели | Разные названия, tooltip и отсутствие throughput в части дерева | Общая фабрика строк метрик |
| P2 | Пустой `children: []` создаёт раскрываемую группу | Стрелка раскрытия без содержимого | Считать группу только при непустых children |
| P2 | DeepSeek Connection показывает общий primary URL, который может быть локальным | Строка описывает другой источник | Использовать адрес DeepSeek, совпадающий с правилами directory |
| P3 | Большой файл объединяет TreeItem, форматирование и разделы | Общие исправления трудно изолировать | Выделить общие элементы и построитель метрик |

Доказательства: `src/ui/quick-access.ts`, `src/token-usage-history.ts`,
`src/api-providers/api-provider-service.ts`. Это аудит представления и потока
данных; он не проверяет доступ к недокументированному Cursor dashboard API.
